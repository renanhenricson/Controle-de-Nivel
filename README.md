# 💧 Controle de Níveis de Água

## 📌 Sobre o projeto

Este projeto foi desenvolvido como atividade prática do curso Técnico em Desenvolvimento de Sistemas. O objetivo é simular o monitoramento do nível de água de um reservatório, exibindo mensagens de alerta coloridas no terminal conforme o nível informado.

## 🎯 Objetivo

Aplicar conceitos de programação estruturada utilizando listas, funções, estruturas condicionais e a biblioteca Colorama para melhorar a visualização das mensagens.

## ⚙️ Funcionalidades

- 🔴 **Nível 1:** Muito baixo (crítico).
- 🟡 **Nível 2:** Baixo.
- 🟢 **Nível 3:** Médio.
- 🩵 **Nível 4:** Alto.
- 🔵 **Nível 5:** Muito alto (alerta).
- ✅ Validação dos níveis informados.
- 🎨 Exibição das mensagens com cores no terminal.
- 🔄 Restauração do estilo padrão após a exibição.

## 🛠️ Tecnologias utilizadas

- Python 3
- Biblioteca Colorama
- Visual Studio Code

## 📚 Conceitos aplicados

- Listas
- Funções
- Estruturas condicionais (`if`, `return`)
- Tratamento de exceções (`try/except`)
- Entrada e saída de dados
- Importação e utilização de bibliotecas externas

## ▶️ Como executar o projeto

**1. Instale o Python**

Certifique-se de que o Python esteja instalado no computador.

**2. Instale a biblioteca Colorama**

```bash
python -m pip install colorama
```

**3. Execute o programa**

Abra o terminal na pasta do projeto e execute:

```bash
python main.py
```

*Observação: substitua `main.py` pelo nome real do arquivo Python, caso seja diferente.*

## 🧪 Exemplo de execução

```text
--------Controle de Níveis de Água--------
Qual o nível do reservatório (1 a 5)? 1
Nível 1: Muito baixo (crítico)
```

A mensagem será exibida em vermelho no terminal.
